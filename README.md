# 李馨茹 · 作品集网站

个人作品集网站，基于 khegai.com 风格设计。

## 本地预览

直接双击 `index.html` 即可在浏览器中打开。

## 目录结构

```
zuopinji/
├── index.html          # 主页面（所有 HTML/CSS/JS 都在这一个文件里）
├── images/
│   ├── cover.jpg       # 首页封面
│   └── thank.jpg       # 结尾 THANK
├── pdfs/
│   ├── resume.pdf      # 简历
│   └── portfolio.pdf   # 作品集
└── videos/
    ├── qingzhao.mp4    # 轻爪品牌设计短片
    ├── dec4.mp4        # 伢伢乐AIGC短片
    └── aug7.mp4        # 三星堆网页展示
```
